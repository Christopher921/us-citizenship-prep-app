# U.S. Citizenship Test Prep

Support, Privacy Policy and Terms of Use pages for the app, served with GitHub Pages.

## Publish
1. Create a GitHub repository (the app uses `us-citizenship-prep-app`) and upload the contents of this folder to the repository root.
2. In the repository, open Settings > Pages, choose "Deploy from a branch", branch `main`, folder `/ (root)`, and save.
3. Your pages will be at `https://<your-username>.github.io/<repo-name>/`, for example `.../privacy.html`, `.../terms.html`, `.../support.html`.
4. Put those URLs into `USCitizenshipPrep/App/Constants.swift` (privacyPolicy, termsOfUse) and into App Store Connect (Privacy Policy URL, Support URL).

## Before you publish
- Confirm the support email (chowchowbuy@gmail.com) is the one you want shown.
- Have the Terms and Privacy Policy reviewed if you want legal assurance; they are plain-language drafts, not legal advice.
